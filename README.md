# AgentC Consulting Homebrew Tap

Homebrew cask distribution for AgentC Consulting apps.

## Scribe

Free, on-device dictation for macOS (Apple Silicon, macOS 13+):

```
brew tap agentc-consulting/tap
brew install --cask scribe
```

More about Scribe: https://github.com/AgentC-Consulting/scribe-app

## HeatPilot

Free menu bar fan control for Apple Silicon Macs (macOS 14+): a cooling slider from Apple's default to Full Blast, and Autopilot for your coding assistant.

```
brew install --cask agentc-consulting/tap/heatpilot
```

More about HeatPilot: https://github.com/AgentC-Consulting/heatpilot
