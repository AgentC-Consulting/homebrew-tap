# AgentC Consulting Homebrew Tap

Homebrew cask distribution for AgentC Consulting apps.

## Scribe

Free, on-device dictation for macOS (Apple Silicon, macOS 13+):

```
brew tap agentc-consulting/tap
brew install --cask scribe
```

More about Scribe: https://github.com/AgentC-Consulting/scribe-app
